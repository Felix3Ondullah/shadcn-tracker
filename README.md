# UI practice workspace

A dark, responsive workspace UI built with Next.js, React, and local shadcn/ui components.

## Development

```bash
npm install
npm run dev
```

## Structure

- `app/` contains the App Router page, root layout, and global styles.
- `components/` contains the workspace, sidebar, top bar, composer, account profile, and brand mark.
- `components/ui/` contains the local shadcn/ui primitives used by the interface.
- `public/` contains static assets.
